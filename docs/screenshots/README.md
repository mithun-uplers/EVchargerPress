# EVChargePress screen layouts

Every screen in the current energy design, captured on 28 Oct 2026 from the design preview (fictional sample data).
Mobile = 390 px wide (iPhone size, 2× resolution). Desktop = 1440 px wide.

To regenerate: set `ENABLE_DESIGN_PREVIEW=1` in `web/.env.local`, run `npm run dev`, open the route listed below.
